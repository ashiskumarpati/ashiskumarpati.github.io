# Dr. Ashis Kumar Pati — Academic Website

A GitHub Pages-ready academic profile website.

## Deploy on GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload all files and folders from this project.
3. In GitHub: **Settings → Pages → Deploy from branch → main / root**.
4. Your website will appear at `https://YOUR-USERNAME.github.io/`.

## Personalize

- Replace the photo placeholder by adding `images/profile.jpg`.
- Replace the GitHub URL in `index.html` with your actual GitHub profile.
- Add students/collaborators to the Team section.
- Add more publications to `js/main.js`.
- Add updates, openings, books, DOI links and project links as needed.

The current publication list is based on the supplied CV. The CV reports 7 journal articles, 10 conference papers, 2 book chapters, 1 ongoing edited book with CRC Press, and 4 published patents.
